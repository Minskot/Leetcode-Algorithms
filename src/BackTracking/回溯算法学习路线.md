# 回溯算法入门学习路线（Backtracking）

### 回溯到底在干什么
想象你在走一个迷宫：每个岔路口你选一条路走，走到死胡同就退回上一个路口，换一条路再试，直到所有路都试完。回溯算法就是这个过程，只不过它走的是"选择树"——每个节点是一次选择，从根到叶子的一条路径就是一个候选答案。
所以一句话：**回溯 = 深度优先地尝试所有可能，走不通就撤销上一步，换一条路继续。**
它专门解决这几类问题：
排列（46 全排列）
组合（77 组合、39 组合总和）
子集（78 子集）
分割（131 分割回文串、93 复原 IP 地址）
棋盘类（51 N 皇后、37 解数独）
### 三个核心要素
写任何回溯题，先问自己三个问题：
路径 path：我已经选了哪些？—— 这是当前在树上的位置
选择列表：我现在还能选什么？—— 排列用 used[] 排除已选的；组合/子集用 start 保证只能往后选
结束条件：什么时候记录答案？—— 全排列是"path 满了"；子集是"每个节点都记录"

// **Standard template**

```java

private void backtrack(路径, 选择列表, 结果) {
    if (满足结束条件) {
        结果.add(new ArrayList<>(路径));   // 一定要复制！
        return;
    }
    for (选择 : 当前可做的选择) {
        做选择;             // path.add(选择)
        backtrack(...);     // 递归进入下一层
        撤销选择;           // path.remove(最后一个) ← 回溯的灵魂
    }
}

```

## 1. 回溯是什么

一句话：**回溯 = 系统地尝试所有可能，走不通就回头（撤销上一步的选择），再换一条路试。**

它本质上是"深度优先搜索（DFS）+ 剪枝（可选）"，适合解决这几类问题：

- 排列（全排列、排列 II）
- 组合（组合、组合总和）
- 子集（子集、子集 II）
- 分割（分割回文串、复原 IP 地址）
- 棋盘 / 网格（N 皇后、解数独、单词搜索）

## 2. 核心三要素：把问题看成"选择树"

做回溯题，第一件事是**画一棵选择树**：从根（空）出发，每个节点代表"当前已经做出的选择"，每条边代表"下一步可选的一个选择"。

写代码时对应三个东西：

1. **路径 path**：已经做出的选择（当前在树上的位置）
2. **选择列表**：当前还能做什么选择（排列用 `used[]` 排除已用的；组合/子集用 `start` 只能往后选）
3. **结束条件**：什么时候把 `path` 记录为答案（叶子？还是每个节点？）

## 3. 万能模板（Java）

```java
private void backtrack(路径, 选择列表, 结果) {
    if (满足结束条件) {
        结果.add(new ArrayList<>(路径));  // 一定要复制，不能直接加 path
        return;
    }
    for (选择 : 当前可做的选择) {
        做选择;              // 路径.add(选择)
        backtrack(...);      // 递归进入下一层
        撤销选择;            // 路径.remove(最后一个) ← 回溯的关键！
    }
}
```

**"撤销选择"就是回溯名字的由来**：递归返回后，要把刚才的尝试抹掉，才能去试下一个选择。

### 46. 全排列

每次从**头**开始选，但不能选用过的元素，所以用 `used[]` 记录。

```java
if (path.size() == nums.length) {           // 结束条件：path 满了
    result.add(new ArrayList<>(path));
    return;
}
for (int i = 0; i < nums.length; i++) {
    if (used[i]) continue;                  // 跳过已用元素
    used[i] = true;
    path.add(nums[i]);                      // 做选择
    backtrack(nums, used, path, result);    // 递归
    used[i] = false;
    path.remove(path.size() - 1);           // 撤销选择
}
```

### 78. 子集

用 `start` 保证**只能往后选**，天然避免重复组合；每个节点都是答案。

```java
result.add(new ArrayList<>(path));          // 每个节点都记录
for (int i = start; i < nums.length; i++) {
    path.add(nums[i]);                      // 做选择
    dfs(nums, i + 1, path, result);         // 递归：下次从 i+1 开始
    path.remove(path.size() - 1);           // 撤销选择
}
```

**记忆技巧**：排列用 `used`，组合/子集用 `start`。为什么？排列在乎顺序（[1,2] 和 [2,1] 不同），所以要能回头选；组合不在乎顺序，只能往一个方向选。

## 5. 手动模拟：画树 + 走一遍

学回溯最有效的方法，是拿 [1,2,3] 全排列亲手模拟一次：

1. 画选择树（根为空，第一层 1/2/3，第二层去掉已用的……）
2. 手写每一步 `path` 和 `used` 的变化
3. 重点体会"递归下去 = 前进一步"，"递归返回 = 退一步（撤销）"

可以配合对话里的交互演示逐帧走一遍。

## 6. 常见变体

- **组合总和（39）**：元素可重复使用 → 递归时 `start` 不 +1
- **去重（40 / 47 / 90）**：先排序，同一层跳过相同的值（`used[i-1]` 或 `i > start` 判断）
- **分割类（131 / 93）**：每次切一段，判断是否合法，合法就递归切下一段
- **棋盘类（51 / 37）**：一行一行/一格一格尝试，冲突就剪枝

## 8. 练习方法

1. 每道题先写模板骨架，再填细节
2. 先画选择树、手动模拟一遍，再写代码
3. 每道题总结三个问题：用 `used` 还是 `start`？答案在节点还是叶子？结束条件是什么？
4. 三遍法：当天做、3 天后重做、一周后再做

## 9. 复杂度速记

- 子集 / 组合：O(2^n)
- 全排列：O(n!)
- 剪枝能大幅加速，但改变不了最坏情况复杂度

## 10. 常见错误清单

- ❌ 忘记撤销选择 → 路径越走越长
- ❌ 直接 `result.add(path)` → 后面修改 path 会把已记录的答案改掉（必须 `new ArrayList<>(path)`）
- ❌ 去重前忘记在入口排序
- ❌ 结束条件放错位置（节点 vs 叶子）
- ❌ 递归参数传递时不小心复用了同一个 list 引用还去修改
